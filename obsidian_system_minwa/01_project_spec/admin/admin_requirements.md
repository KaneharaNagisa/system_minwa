# 管理画面 要件定義書

## 1. 目的・認証

- 民話と関連画像を登録・管理する管理者専用画面とする。
- エンドユーザー画面のBasic認証とは別に、管理者用ログイン認証（または強固なパスワード認証）を設ける。
- 認証情報をソースコードやリポジトリに記載しない。

## 2. 民話一覧

- 登録済み民話を一覧表示し、市町村・タイトル・更新日で検索・並び替えできる。
- 1ページの表示件数は最大15件とし、対象件数が16件以上の場合はページネーションを表示する。
- 論理削除済みの民話は通常の一覧から除外する。

## 3. 登録・編集・削除

- 民話の新規登録と既存データの編集を行える。
- 民話本文はMarkdown形式で記述・編集できる。
- タイトル、よみがな、該当市町村、あらすじ、本文、出典、テーマタグを管理する。
- ゆかりの地は名称・住所・GoogleマップURLを登録する。
- 既存民話の削除は論理削除とし、データを物理削除しない。削除済みデータはエンドユーザー画面に表示しない。

## 4. 画像

- 絵本風のメインイラストと本文中の挿絵をアップロード・管理できる。
- 本文中の画像はMarkdown記法 `![説明](画像パス)` で挿入できる。
- 画像URLまたはアップロード済み画像のパスをMarkdownに利用できる。

## 5. 執筆アシスト

- 本文の不要な改行を整える補助機能を提供する。
- あらすじの自動生成を補助する機能を提供する。
- 整形・要約の結果は管理者が確認・編集してから保存する。結果を自動で公開しない。

## 6. 出典・著作権チェック

- 民話ごとに出典元を記録できる。
- 出典元の明記と、表現を書き直したことを確認するチェックボックスを設ける。
- 各確認状態を民話データとともに記録し、後から確認できるようにする。
- チェックボックスは権利処理そのものを保証するものではない。利用可否の確認は管理者が行う。

## 7. 制約

- 一覧・編集・画像管理等は管理者認証後のみ利用可能とする。
- エンドユーザー画面は限定公開・閲覧専用とし、管理操作を公開しない。
- データ項目の共通事項は [[../project_spec_common]] に従う。
