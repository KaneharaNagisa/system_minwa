# エンドユーザー画面 要件定義書

## 1. 目的・対象

- 長野県の民話を共有メンバーが閲覧するための限定公開・閲覧専用画面とする。
- エンドユーザーは民話の登録・編集・削除を行えない。

## 2. アクセス制御

- サイト全体にHTTP Basic認証を適用し、認証された共有メンバーのみ閲覧可能とする。
- 認証情報はソースコードやリポジトリに記載せず、安全な環境設定で管理する。

## 3. デザイン・表示

- 和紙テクスチャー、明朝体、和柄を用いた和モダンの世界観とする。
- トップページは和紙色の背景、濃墨ヘッダー、金色の飾り線、角の装飾、半透明の紙カードで構成する。
- 市町村選択はカード型ボタンと市町村プルダウンで行える。
- 民話カードは市町村名、タイトル、よみがな、あらすじを表示し、詳細ページへ遷移する。
- 詳細ページは読みやすい本文領域と、文字サイズ小・中・大の切り替えボタンを備える。
- スマートフォン、タブレット、PCの画面幅に合わせて一覧と検索エリアをレスポンシブ表示する。
- 民話の一覧・詳細に、物語の情景を伝える絵本風イラストを表示できる。
- 本文中の挿絵も表示でき、画像は和紙デザインに馴染む表示とする。
- デザイン参考は [[../project_spec_common]] に記載したプロトタイプとする。プロトタイプの画面・機能を完成済み実装として扱わない。

## 4. トップページ・検索

- 長野県のシルエット地図を表示し、市町村ごとの登録民話件数を示す。
- 地図上の市町村を選択すると、その市町村の民話に絞り込む。
- 市町村プルダウン、キーワード検索、テーマタグ検索を提供する。
- キーワード検索対象はタイトル・あらすじ・本文とする。
- 市町村・タグ・キーワードの条件は併用して検索できる。
- 削除済み民話は件数、検索結果、一覧に含めない。

## 5. 民話詳細

- 管理画面で登録されたMarkdownをHTMLとして表示する。見出し、強調、本文中の画像などを扱う。
- Markdown画像は本文の流れに合わせ、和紙デザインに馴染むよう表示する。
- ふりがなの表示・非表示をワンクリックで切り替える。
- ブラウザ標準の音声合成（Web Speech API等）で読み上げを再生・停止できる。
- 文字サイズを小・中・大から選択できる。
- メインイラスト、タイトル、本文、出典などの登録情報を表示する。
- 読み上げ機能が利用できないブラウザでは、本文閲覧を妨げない。

## 6. ゆかりの地・関連民話

- 登録された史跡・ゆかりの地の名称と住所を表示する。
- Googleマップへの外部リンクを表示する。
- 詳細ページ下部に、同じ市町村または同じテーマタグを持つ別の民話を表示する。
- 関連民話は閲覧中の民話自身と削除済み民話を除外する。

## 7. 制約

- 本画面では閲覧・検索のみを提供し、管理機能を設けない。
- 認証、民話データ、画像の実装方法は管理画面および共通仕様に従う。
